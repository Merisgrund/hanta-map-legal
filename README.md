# Hanta-Map Legal

Statische Rechteseite fuer Hanta-Map: Datenschutz, Impressum und Nutzungsbedingungen.

Dieses Mini-Projekt ist absichtlich getrennt vom App-Repo. Es enthaelt keinen App-Code, keine Datenlogik und keine Build-Abhaengigkeiten.

## Empfohlenes Hosting

### GitHub Pages

1. Neues separates GitHub-Repo erstellen, z. B. `hanta-map-legal`.
2. Nur die Dateien aus diesem Ordner hochladen.
3. In GitHub unter `Settings -> Pages` die Quelle `Deploy from a branch` waehlen.
4. Branch `main`, Ordner `/root` auswaehlen.
5. Die URL sieht danach typischerweise so aus:
   `https://<github-user>.github.io/hanta-map-legal/`

Fuer Google Play kann als Privacy-Policy-URL z. B. diese URL verwendet werden:

`https://<github-user>.github.io/hanta-map-legal/privacy.html`

## Wichtig

Bei kostenloser GitHub-Pages-Nutzung kann das Legal-Repo je nach Account/Plan oeffentlich sein. Das App-Repo muss dafuer nicht oeffentlich werden. In diesem Repo liegen nur die Rechtstexte.

## Vor Store-Veröffentlichung pruefen

- Stimmt die vollstaendige Anbieteranschrift?
- Ist Google AdMob/Google Ads bereits aktiv oder nur geplant?
- Gibt es Analytics, Crash-Reporting, Push, Login oder ein Backend?
- Stimmen Google-Play-Data-Safety-Angaben und Datenschutzerklaerung ueberein?
